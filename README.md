# This is the working version of the Sidebar in Angular. 
This branch includes:
- Springboot application that hosts an angular application
- An Angular application with an extra component called "sidebar"
  - The component includes an almost one-to-one copy of the sidebar from Figma.
  - NOTE: all the designs are made from pure CSS and NOT Bootstrap, if you would like to switch over to Bootstrap, head over to [this](https://ng-bootstrap.github.io/#/getting-started) website for resources

Clone this branch into your local machine and immediately switch the remote branch of your own and push your changes to that.
## Please DO NOT push anything into this branch after you clone it.
